# Web app

React + TypeScript + Vite. It talks to the API in `backend/main.py`.

- `src/App.tsx`: the page (area, period, key figures, burn calendar, charts, downloads).
- `src/MapPicker.tsx`: Leaflet map where the user draws the area.
- `src/Chart.tsx`: ECharts wrapper. Every chart can be saved as an image.
- `src/api.ts`: API client and types.

Run instructions are in the README at the repo root.
